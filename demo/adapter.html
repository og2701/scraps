adapter

The panel below is someone else's design system: plain markup with data-slot attributes and flat, rounded, corporate CSS. There is not one data-scrap attribute in it and not one scraps component.

One call papers the whole thing, and the disposer hands it back untouched. 

const stop = Scraps.adapt({
  '[data-slot="card"]': 'card',
  '[data-slot="button"]': 'button',
  '[data-slot="button"][data-variant="secondary"]': { type: 'button', color: 'white' },
  '[data-slot="button"][data-disabled]': { type: 'button', color: 'kraft', boil: false },
  '[data-slot="badge"]': { type: 'badge', color: 'marigold' },
  '[data-slot="input"]': 'input',
  '[data-slot="separator"]': 'separator',
  '[data-slot="dialog"]': 'dialog',
})

stop()   // every element back to plain markup

what the state selectors do

Entries are read in order and the last match wins, so [data-slot="button"][data-disabled] overrides the plain button rule above it. The observer watches only the attributes those selectors name, so a component flipping data-disabled or data-open at runtime re-cuts its paper on the spot.
